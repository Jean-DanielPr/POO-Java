# ⚔️ Academia de Heróis do Reino de Arcádia

Este é um projeto prático desenvolvido em **Java Puro (Java Core)** focado na aplicação prática de conceitos de Programação Orientada a Objetos (POO), lógica de programação avançada e manipulação dinâmica de dados em memória. 

O sistema simula o controle, gerenciamento e regras de negócio lógicas para uma academia de treinamento de heróis medievais e fantásticos.

---

## 🎯 Principais Objetivos do Projeto

* **Fixação de POO:** Aplicação real de conceitos como Abstração, Encapsulamento, Classes, Atributos e Métodos.
* **Manipulação de Dados Dinâmicos:** Armazenamento, filtragem e gerenciamento de informações utilizando estruturas dinâmicas de dados (`ArrayList`).
* **Tratamento de Exceções:** Implementação de mecanismos de defesa de código para tratar entradas de dados inválidas e evitar falhas na execução do programa (Crash).
* **Versionamento de Código:** Gerenciamento do histórico do projeto de forma profissional utilizando Git e GitHub.

---

## 🛠️ Tecnologias e Conceitos Utilizados

* **Linguagem:** Java (Versão JDK de Estudos)
* **Paradigma:** Programação Orientada a Objetos (POO)
* **Estrutura de Dados:** Listas Dinâmicas (`java.util.ArrayList`)
* **Interface:** Aplicação estruturada via Terminal/Console (`System.out`)
* **IDE Utilizada:** IntelliJ IDEA / Ecossistema JetBrains `.idea`

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o **Java Development Kit (JDK)** instalado em sua máquina.
2. Clone este repositório ou faça o download da pasta do projeto:
   ```bash
   git clone https://github.com
   ```
3. Navegue até a pasta `Projetos completos/Academia de Herois do Reino de Arcadia`.
4. Abra o projeto em sua IDE de preferência (IntelliJ, Eclipse ou VS Code).
5. Execute a classe principal (`Main`) que contém o ponto de entrada do sistema.
